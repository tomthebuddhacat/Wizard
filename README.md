# Read Me

## A brief introduction to the project.

---

### Introduction to the project.
Wizard is a Paper plugin written in Java to make managing a Minecraft server easier. It's intended for use by 
server owners, managers and developers who run servers and want to keep it simple and not have to download 
dozens of plugin.

---

### Building the project.

To build the project or make modifications to suit your needs, follow the instructions below.

### 1. Clone the Repository

```bash
git clone https://github.com/tomthebuddhacat/Wizard.git
```

### 2. Navigate to the Project Directory

```bash
cd Wizard
```

### 3. Build the Project

```bash
./gradlew shadowJar
```
The compiled JAR will be generated in the `build/libs` directory.


> **Note:** On Windows, use `gradlew.bat` instead of `./gradlew`.
